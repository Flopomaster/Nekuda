# נקודה · Nekuda

אפליקציה בשביל אליקים: ניהול כספים ומשימות אישי, בעברית, כ-PWA שמותקנת על האייפון ועובדת גם במחשב.

## מה יש בפנים

**כספים**
- רישום הוצאות והכנסות: סכום, תאריך, קטגוריה, שם העסק (עם השלמה אוטומטית ובחירת קטגוריה לפי שימוש קודם), אמצעי תשלום והערה
- **ייבוא מהבנק**: העלאת קובץ Excel/CSV של תנועות (נבדק על Pepper), עם:
  - סיווג אוטומטי לפי שם העסק, שלומד מהבחירות שלך
  - סינון העברות לחיסכון והעברות בין החשבונות שלך
  - זיהוי כפילויות, כך שאפשר לייבא שוב את אותה תקופה
- **חיבור אוטומטי לבנק ולאשראי**: כל משתמש מחבר את החשבונות שלו מההגדרות, והתנועות מתעדכנות כל לילה (ראו למטה)
- בחירת תקופה (החודש / חודש שעבר / 3 חודשים / השנה / טווח מותאם) עם תרשים עוגה לפי קטגוריות, השוואת הכנסות מול הוצאות ותצוגת טבלה
- ייצוא דוח מפורט לכל תקופה: **PDF**, **Excel** (4 גיליונות) ו-**PNG**
- יעדים חודשיים: יעד חיסכון ויעד הכנסה
- המלצות חיסכון מבוססות חוקים: קטגוריות מעל הממוצע, הוצאות קטנות שמצטברות, עסקים חוזרים, מנויים, תקציב יומי שנותר ליעד

**משימות**
- חד-פעמיות לפי תאריך, או קבועות: יומיות / שבועיות (ימים נבחרים) / חודשיות
- שעת תזכורת, קטגוריה צבעונית ותתי-משימות
- תצוגות: היום, לוח שנה, כל המשימות, התקדמות (אחוז השלמה שבועי/חודשי + רצפים 🔥)
- משימה שלא בוצעה עוברת ל״באיחור״ ונשלח סיכום בפוש בערב

**כללי**: בורדו / ורוד עתיק / לבן, מצב בהיר וכהה, נעילת PIN + Face ID, עובד גם בלי אינטרנט (תצוגה).

## ארכיטקטורה

| חלק | טכנולוגיה |
|---|---|
| אפליקציה | React 19 + Vite + TypeScript, PWA (vite-plugin-pwa, service worker ב-`src/sw.ts`) |
| נתונים | Supabase (Postgres + Auth), RLS על כל טבלה: כל משתמש רואה רק את הנתונים שלו (עד 5 משתמשים) |
| פושים | Web Push (VAPID). `pg_cron` מפעיל כל דקה את `supabase/functions/send-reminders` |
| תרשימים | Recharts. הפלטה נבדקה לעיוורון צבעים |
| ייצוא | html-to-image + jsPDF, ExcelJS |

סכמת מסד הנתונים נמצאת ב-`supabase/migrations`. מפתחות ה-VAPID הפרטיים וסוד ה-cron שמורים ב-`private.config` במסד הנתונים ולא בקוד.

## סנכרון אוטומטי עם הבנק

כל לילה (בסביבות 04:17) רץ ב-GitHub Actions תהליך (`.github/workflows/bank-sync.yml` → `sync/`) שמושך את התנועות מכל החשבונות המחוברים, בעזרת [israeli-bank-scrapers](https://github.com/eshaham/israeli-bank-scrapers).

**נתמכים:** כאל, מקס, ישראכרט, אמריקן אקספרס, הפועלים, לאומי, דיסקונט, מזרחי, הבינלאומי, מרכנתיל, יהב, אוצר החייל, מסד, איגוד, פאג"י.
**לא נתמכים:** Pepper, שעובד רק כאפליקציה ובלי אתר (ממנו מייבאים קובץ), ובנקים שדורשים קוד SMS בכל כניסה.

**אבטחה:**
- פרטי ההתחברות מוצפנים **בדפדפן**: AES-256-GCM, כשהמפתח עטוף ב-RSA-OAEP-3072 (`src/lib/sealedBox.ts`).
- מסד הנתונים שומר רק את הטקסט המוצפן, ומשתמשים לא יכולים לקרוא אותו בחזרה (הרשאות ברמת העמודה, בנוסף ל-RLS).
- המפתח הפרטי קיים רק בסוד `NEKUDA_SYNC_SECRET` ב-GitHub. הוא נוצר בדפדפן בהגדרה הראשונית ומוצג פעם אחת בלבד.
- התהליך הלילי לא מקבל גישה למסד הנתונים. הוא מדבר רק עם `supabase/functions/bank-sync`, בעזרת טוקן שה-hash שלו שמור ב-`private.config`.

**הגדרה חד-פעמית:** באפליקציה נכנסים ל**הגדרות**, לוחצים **חיבור לבנק ולאשראי** ואז **הגדרה ראשונית**, ושומרים את המפתח שמוצג כסוד `NEKUDA_SYNC_SECRET` ב-GitHub (Settings → Secrets and variables → Actions). אחר כך כל משתמש מחבר את החשבונות שלו.

אפשר להריץ סנכרון ידנית מ-GitHub: **Actions → Bank sync → Run workflow**.

## הרצה מקומית

```bash
npm install
npm run dev
```

## העלאה ל-Vercel

1. ב-[vercel.com](https://vercel.com): **Add New → Project**, בוחרים את הריפו `Nekuda` ולוחצים **Deploy**. ההגדרות כבר ב-`vercel.json`, ואין צורך במשתני סביבה.
2. ב-Supabase: **Authentication → URL Configuration**, ומגדירים את **Site URL** לכתובת שקיבלתם מ-Vercel (למשל `https://nekuda.vercel.app`), כדי שקישור אימות המייל יחזיר לאפליקציה.

## התקנה על האייפון

1. פותחים את הכתובת ב**ספארי** ← כפתור השיתוף ← **״הוספה למסך הבית״**
2. פותחים את נקודה מהאייקון, נרשמים ומגדירים קוד PIN
3. **הגדרות ← התראות לטלפון ← הפעלה**, ואפשר לשלוח התראת בדיקה
4. **הגדרות ← אבטחה ← Face ID** להפעלה

> פושים באייפון דורשים iOS 16.4 ומעלה, ועובדים רק מהאפליקציה המותקנת על מסך הבית.
